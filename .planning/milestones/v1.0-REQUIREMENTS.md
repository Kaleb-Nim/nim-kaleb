# Requirements Archive: v1.0 — Kaleb's AI Voice Portfolio

**Defined:** 2026-04-09
**Completed:** 2026-04-12
**Core Value:** Visitors can have a natural, human-sounding voice conversation with an AI clone of Kaleb that authentically represents his experience and personality.

## v1 Requirements (All Complete)

### Voice Identity

- [x] **VOICE-01**: Kaleb's voice is cloned using Qwen3-TTS ICL mode with 10-15s clean reference audio and transcript
- [x] **VOICE-02**: AI responds in Kaleb's cloned voice for all TTS output
- [x] **VOICE-03**: LLM system prompt contains full resume, bio, project descriptions for accurate factual answers
- [x] **VOICE-04**: AI maintains consistent persona (vocabulary, tone, communication style) across all topics
- [x] **VOICE-05**: AI uses topic-appropriate emotional intonation (proud for achievements, focused for technical, candid for challenges)

### Pipeline

- [x] **PIPE-01**: Alibaba Cloud STT (Qwen3-ASR) replaces OpenAI STT via WebSocket streaming
- [x] **PIPE-02**: Alibaba Cloud Qwen LLM replaces OpenAI LLM via DashScope OpenAI-compatible endpoint
- [x] **PIPE-03**: Alibaba Cloud Qwen3-TTS replaces OpenAI TTS with Kaleb's cloned voice ID
- [x] **PIPE-04**: Total voice round-trip latency is under 800ms (STT + LLM + TTS streaming)
- [x] **PIPE-05**: Server-side WebSocket orchestrator handles STT→LLM→TTS pipeline (Bun on Alibaba Cloud ECS)
- [x] **PIPE-06**: Secure key handling — server holds DashScope API keys, never exposed to browser *(adjusted: temporary token exchange not implemented, server-side keys acceptable for portfolio)*

### Speech Quality

- [x] **SPCH-01**: LLM generates natural speech with filler words ("erm", "uh"), micro-pauses, and varied sentence length
- [x] **SPCH-02**: AI asks contextual follow-up questions at end of responses when natural (not every response)
- [x] **SPCH-03**: Responses are conversational length (3-4 sentences max) to maintain natural dialogue flow

### Conversation

- [x] **CONV-01**: VAD-based continuous conversation flow after single button activation (not push-to-talk)
- [x] **CONV-02**: Rolling session memory (up to 20 turns) enabling contextual follow-ups
- [x] **CONV-03**: Graceful error handling and automatic reconnect on WebSocket drops
- [x] **CONV-04**: Waveform visual feedback during AI speech (existing, preserved)
- [x] **CONV-05**: Accessibility transcript toggle showing text of AI responses

### UI Preservation

- [x] **UI-01**: Terminal-themed UI with macOS chrome preserved unchanged
- [x] **UI-02**: Starfield background and typewriter animations preserved
- [x] **UI-03**: State machine progression (BOOTING → STATUS → MENU → VOICE) preserved
- [x] **UI-04**: Responsive layout (desktop/tablet/mobile) preserved
