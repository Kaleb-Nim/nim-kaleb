## Overview

Migrated an existing terminal-themed portfolio's voice feature from OpenAI Realtime API to an Alibaba Cloud (DashScope) cascaded pipeline — Qwen3-ASR for STT, Qwen LLM for language, and Qwen3-TTS for voice cloning — while preserving the full existing UI experience. Deployed to production with Vercel frontend + Alibaba Cloud ECS WebSocket server.

## Milestone Summary

**Key Decisions:**
- Alibaba Cloud over OpenAI Realtime — full pipeline control, voice cloning via Qwen3-TTS
- Document-based context over RAG — portfolio scope doesn't need dynamic retrieval
- Keep terminal UI unchanged — strong existing design, focus effort on voice pipeline
- TTS server_commit gating — DashScope sends response.done per segment; only forward after session.finish
- AI greets first on connect — better UX, visitor hears Kaleb immediately
- Alibaba Cloud ECS over Railway — user has $300 free credits, keeps infra on 2 providers

**Key Accomplishments:**
1. Voice cloned via Qwen3-TTS with Kaleb's reference audio (voice_id enrolled and verified)
2. Bun WS server with full DashScope ASR→LLM→TTS streaming pipeline
3. Conversational AI with proactive greeting, barge-in handling, 20-turn session memory
4. Terminal UI preserved with accessibility fixes (reduced-motion, ARIA transcript toggle)
5. 10 automated tests (1 UI + 9 backend/WS pipeline)
6. Production deployed: nim-kaleb.vercel.app + wss://ws.kalebnim.dev (Alibaba Cloud ECS, Singapore)

**Issues Deferred:**
- TTS playback quality: overlapping audio, cut-offs, inconsistent barge-in behavior

**Technical Debt Incurred:**

- next.config.ts git log fallback triggers on Vercel build (no git repo in build env)
