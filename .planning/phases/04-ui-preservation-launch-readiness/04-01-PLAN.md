In `app/hooks/useTypewriter.ts`, inside the `useEffect` callback, add a reduced-motion check immediately after the existing `if (!text)` early return (after line 20). Insert the following block:

```typescript
    // Respect reduced motion — show text instantly
    const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    if (prefersReduced) {
      setDisplayedText(text);
      setIsComplete(true);
      onComplete?.();
      return;
    }
```

This goes BEFORE the existing `let currentIndex = 0;` line. The rest of the hook remains unchanged. When `prefers-reduced-motion: reduce` is active, the typewriter interval never fires — text appears instantly and `onComplete` fires immediately, allowing the state machine to progress without delay.

Note: `globals.css` already has CSS-level `prefers-reduced-motion: reduce` that disables CSS animations (cursor blink, fadeIn). This JS check covers the `setInterval` path that CSS cannot reach.
  </action>
