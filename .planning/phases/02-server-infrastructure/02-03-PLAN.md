Refactor `app/hooks/useRealtimeVoice.ts` in-place. Keep all reusable audio functions. Change only the WS connection and message protocol.

**Keep unchanged (reuse as-is):**
- `pcm16ToFloat32()` — used for audio playback
- `base64ToArrayBuffer()` — used for audio playback
- `scheduleAudioChunk()` — used for audio playback
- `float32ToPcm16Base64()` — used for mic capture encoding
- `downsample()` — used for mic capture resampling
- All type exports (`RealtimePhase`, `RealtimeStatus`)
- Hook return interface `{ status, analyserRef, connect, disconnect, isConnected }`

**Change 1: WS Server URL**
- Replace the OpenAI WebSocket URL with the Bun WS server
- Add a constant: `const WS_SERVER_URL = process.env.NEXT_PUBLIC_WS_SERVER_URL ?? 'ws://localhost:8080';`
- Connection: `new WebSocket(WS_SERVER_URL + '/ws')` — no subprotocol headers needed (server handles auth)

**Change 2: Remove OpenAI session token fetch**
- Delete the `fetch('/api/realtime/session', { method: 'POST' })` call
- No token exchange needed — browser connects directly to Bun server

**Change 3: Audio capture sample rate**
- Change `const SAMPLE_RATE = 24000;` to `const MIC_SAMPLE_RATE = 16000;` for capture (ASR needs 16kHz)
- Add `const PLAYBACK_SAMPLE_RATE = 24000;` for TTS audio playback
- AudioContext for mic capture: `new AudioContext({ sampleRate: MIC_SAMPLE_RATE })`
- A SEPARATE AudioContext for playback: create a `playbackCtxRef = useRef<AudioContext | null>(null)` at `new AudioContext({ sampleRate: PLAYBACK_SAMPLE_RATE })`
- Update `scheduleAudioChunk` to use `playbackCtxRef.current` and `PLAYBACK_SAMPLE_RATE`
- Update `downsample()` call: `downsample(input, ctx.sampleRate)` — downsamples from system rate to MIC_SAMPLE_RATE (16kHz)

**Change 4: Message protocol (send)**
- Audio append: change `{ type: 'input_audio_buffer.append', audio: b64 }` to `{ type: 'audio.append', data: b64 }`
- On WS open, send `{ type: 'session.start' }` instead of waiting for `session.created`

**Change 5: Message protocol (receive) — update handleMessage:**
- `session.ready` -> `setPhase('listening'); transitionTo('VOICE_ACTIVE');`
- `transcript.partial` -> `setStatus(prev => ({ ...prev, transcript: event.text }))`
- `transcript.final` -> `setStatus(prev => ({ ...prev, transcript: event.text }))`
- `response.audio.delta` -> `scheduleAudioChunk(base64ToArrayBuffer(event.delta))` and `setPhase('responding')` on first chunk
- `response.text.delta` -> `setStatus(prev => ({ ...prev, responseText: prev.responseText + event.delta }))`
- `response.done` -> `setPhase('listening'); setStatus(prev => ({ ...prev, responseText: '' }))` (clear for next turn)
- `error` -> `setStatus(prev => ({ ...prev, phase: 'error', error: event.message }))`
- Remove all OpenAI-specific handlers: `session.created`, `input_audio_buffer.speech_started`, `response.created`, `response.audio_transcript.delta`, `response.audio.done`

**Change 6: Auto-reconnect (CONV-03)**
Add reconnect logic inside the `connect` function:
- Add refs: `retriesRef = useRef(0)`, `reconnectTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null)`, `intentionalCloseRef = useRef(false)`
- Max retries: 5
- On `ws.onclose`: if `!intentionalCloseRef.current && retriesRef.current < 5`:
  - Calculate delay: `Math.min(1000 * 2 ** retriesRef.current, 30000)`
  - Log `[ws] reconnecting in ${delay}ms (attempt ${retriesRef.current + 1}/5)`
  - `reconnectTimerRef.current = setTimeout(() => { retriesRef.current++; /* re-call internal connect logic */ }, delay)`
- On `ws.onopen`: reset `retriesRef.current = 0`
- `disconnect()`: set `intentionalCloseRef.current = true`, clear reconnect timer, then close WS
- `connect()`: set `intentionalCloseRef.current = false`, reset retries to 0

**Change 7: Clean up on reconnect**
When reconnecting, clean up mic/audio resources and re-establish them fresh. The `session.start` message sent on WS open tells the server to create fresh DashScope sessions.

**Do NOT change:**
- The `'use client'` directive at top of file
- Import structure (React hooks from 'react')
- The `UseRealtimeVoiceOptions` interface
- The hook return signature

**Add to .env.local:**
- `NEXT_PUBLIC_WS_SERVER_URL=ws://localhost:8080` (for local dev; will be set to Railway URL in production)
