**ws-server/src/types.ts** — Define the browser<->server protocol as discriminated unions:
```typescript
// Browser -> Server
export type BrowserMessage =
  | { type: 'audio.append'; data: string }      // base64 PCM16 16kHz mono
  | { type: 'audio.end' }                        // manual end-of-speech signal
  | { type: 'session.start' }                    // initialize/re-initialize DashScope sessions

// Server -> Browser
export type ServerMessage =
  | { type: 'session.ready' }                    // server ready for audio
  | { type: 'transcript.partial'; text: string } // interim ASR result
  | { type: 'transcript.final'; text: string }   // final ASR result
  | { type: 'response.audio.delta'; delta: string } // base64 PCM 24kHz chunk
  | { type: 'response.text.delta'; delta: string }  // LLM text chunk for transcript display
  | { type: 'response.done' }                    // TTS finished for this turn
  | { type: 'error'; message: string }           // error from any pipeline stage

export function isValidBrowserMessage(msg: unknown): msg is BrowserMessage {
  if (typeof msg !== 'object' || msg === null || !('type' in msg)) return false;
  const m = msg as { type: string };
  return ['audio.append', 'audio.end', 'session.start'].includes(m.type);
}
```

**ws-server/src/dashscope/asr.ts** — Create the DashScope ASR WebSocket client:

```typescript
export interface AsrCallbacks {
  onTranscriptPartial: (text: string) => void;
  onTranscriptFinal: (text: string) => void;
  onError: (message: string) => void;
}
```

Export `createAsrSession(callbacks: AsrCallbacks): WebSocket`:
- Open WebSocket to `wss://dashscope-intl.aliyuncs.com/api-ws/v1/realtime?model=qwen3-asr-flash-realtime`
- Set Authorization header: `{ headers: { Authorization: 'Bearer ' + process.env.DASHSCOPE_API_KEY } }`
- On open, send `session.update` message:
  ```json
  {
    "type": "session.update",
    "event_id": "evt_asr_init",
    "session": {
      "modalities": ["text"],
      "input_audio_format": "pcm",
      "sample_rate": 16000,
      "input_audio_transcription": { "language": "en" },
      "turn_detection": {
        "type": "server_vad",
        "threshold": 0.0,
        "silence_duration_ms": 400
      }
    }
  }
  ```
- On message, parse JSON and route:
  - `conversation.item.input_audio_transcription.completed` -> call `callbacks.onTranscriptFinal(msg.transcript)`
  - `input_audio_buffer.speech_started` -> log `[asr] speech started`
  - `error` -> call `callbacks.onError(msg.error?.message ?? 'ASR error')`
- On close, log `[asr] WebSocket closed`
- On error, call `callbacks.onError('ASR WebSocket connection error')`

Export `forwardAudioToAsr(asrWs: WebSocket, base64Audio: string): void`:
- Send `{ type: 'input_audio_buffer.append', event_id: 'evt_audio_' + Date.now(), audio: base64Audio }` as JSON string
- Only send if `asrWs.readyState === WebSocket.OPEN`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Bun WS Server | Untrusted audio and control messages from any visitor |
| Bun WS Server -> DashScope | Authenticated server-side connection using API key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | ws-server/src/index.ts | mitigate | All DashScope connections server-side; API key in process.env only; never serialized in ServerMessage |
| T-02-02 | Tampering | ws-server/src/index.ts websocket.message | mitigate | Validate every browser message with isValidBrowserMessage() before routing; reject unknown types with error |
| T-02-03 | Denial of Service | ws-server/src/session.ts | mitigate | cleanup() closes all DashScope WebSockets on browser disconnect; prevents orphaned sessions |
| T-02-04 | Spoofing | ws-server/src/index.ts CORS | accept | Public portfolio — CORS allows all origins; no user auth needed |
</threat_model>
