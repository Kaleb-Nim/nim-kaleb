# Quick Task 260627-4tk — Mobile quick-bar destination labels

## Problem

On the home page quick-bar, each link renders a lowercase prefix label
(`github: `) + the handle value (`[Kaleb-Nim] ↗`). Below 480px the
`.quick-label` prefix is hidden by CSS (`globals.css:149-151`), so mobile users
see only `[Kaleb-Nim] ↗`, `[kaleb-nim] ↗`, etc. — with no indication of where
each link goes.

## Decision (from user)

> "Replace the Kaleb Nim text to literal words GitHub or LinkedIn. For mobile view"

On **mobile only**, swap the handle value for the literal destination word.
Desktop is unchanged (keeps `github: [Kaleb-Nim] ↗`).

| Link     | Desktop value (>480px) | Mobile word (≤480px) |
|----------|------------------------|----------------------|
| github   | `Kaleb-Nim`            | `GitHub`             |
| linkedin | `kaleb-nim`            | `LinkedIn`           |
| email    | `kaleb.nim@gmail`      | `Email`              |
| cv       | `download`             | `Resume`             |
| youtube  | `how I built this`     | `YouTube`            |

Brackets `[...]` and trailing glyphs (`↗` / `⬇`) are preserved at both sizes.

## Tasks

### Task 1 — Add `dest` field to Link data
- **files:** `app/lib/sections.ts`
- **action:** Add `dest: string` to the `Link` interface and a capitalized
  destination word to each `LINKS` entry.
- **verify:** `bun run build` typechecks; `LINKS` only consumed by HomePage.
- **done:** Every link carries its mobile destination word.

### Task 2 — Dual-render value/dest + CSS swap
- **files:** `app/components/HomePage.tsx`, `app/globals.css`
- **action:** Inside each quick-bar `<a>`, render `.quick-value` (handle) and
  `.quick-dest` (destination word) inside the brackets. In `globals.css`, hide
  `.quick-dest` by default and, in the existing `max-width: 480px` block, hide
  `.quick-value` + show `.quick-dest` alongside the already-hidden `.quick-label`.
- **verify:** DevTools at 375px shows `[GitHub] ↗ [LinkedIn] ↗ …`; desktop
  unchanged. `bun run lint` clean.
- **done:** Mobile shows destination words; desktop shows handles.
