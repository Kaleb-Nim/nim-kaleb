**1b. CognitiveStatus.tsx — glyph rendering (per R-02):**

Add a helper to determine the glyph for a cell:
```typescript
function glyphFor(cell: StatusCell): string | null {
  if (!cell.href) return null;
  if (cell.href.startsWith('mailto:')) return null;       // email — no glyph
  if (cell.href.endsWith('.pdf')) return '⬇';        // ⬇ download
  if (cell.external) return '↗';                     // ↗ external
  return null;
}
```

In `renderCell` (used by twoColumn / desktop):
- Append the glyph INSIDE the `<a>` so the underline includes it: render `{displayValue}{glyph && <span className={styles.externalGlyph}>{glyph}</span>}`.
- Do NOT change `padEnd` width — the glyph is visual only and desktop alignment is computed from `cell.value` text, which is unchanged. The pre-formatted `padEnd` ensures column alignment is preserved; the glyph appears AFTER the padded text but inside the link, which is acceptable as it occurs at end-of-line for the left column or end-of-row for the right column.
  - **Important:** for the left column in twoColumn mode, the glyph appears INSIDE the padded space (after `value` but before the trailing spaces). Verify the right column label still starts at the correct character position. If alignment breaks visually, switch to rendering the glyph OUTSIDE the `<a>` for desktop only by branching on a new `inline` argument and computing pad differently. - The label text (`{cell.label}: `) should remain OUTSIDE the link (current behavior). However the requirement says "the entire row containing a link should be tappable." To make the whole row tappable while keeping the label visible, restructure so the `<a>` wraps the entire row:

**2c. Wire into `app/page.tsx` (per R-04):**

- Add `useState`/`useEffect` for `isCoarsePointer` detection using `window.matchMedia('(pointer: coarse)')`. Check on mount and listen for changes:
  ```tsx
  const [isCoarsePointer, setIsCoarsePointer] = useState(false);
  useEffect(() => {
    const mq = window.matchMedia('(pointer: coarse)');
    const update = () => setIsCoarsePointer(mq.matches);
    update();
    mq.addEventListener('change', update);
    return () => mq.removeEventListener('change', update);
  }, []);
  ```
  Rationale: `(pointer: coarse)` is more idiomatic than reusing `isDesktop` because it captures touch capability rather than just viewport width (covers tablets in landscape, etc.). Per requirement "pick whichever is more idiomatic" — coarse pointer is the modern web platform answer.
