## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `/api/analytics/*` | Untrusted client-submitted event data crosses here |
| Route handler → Neon Postgres | Server-controlled SQL via tagged-template (parameterized) |
| Browser → Vercel Analytics ingest | Vercel-managed, out of scope for our threat model |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-l3f-01 | Tampering | `POST /api/analytics/transcript` text field | mitigate | Hard cap `text.slice(0, 8000)` server-side; schema `text text not null` accepts any string but size-bounded. |
| T-l3f-02 | Tampering | `sessionId` sent by client | mitigate | Server validates `typeof sessionId === 'string'`; `session_id` FK with `on delete cascade` bounds damage; UUID v4 space makes forgery impractical but still records garbage if attacker brute-forces — accept, no auth. |
