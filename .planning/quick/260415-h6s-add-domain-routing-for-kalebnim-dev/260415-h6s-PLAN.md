# Quick Task: Add Domain Routing for kalebnim.dev

## Goal
Make the portfolio accessible at `kalebnim.dev` (and `www.kalebnim.dev`) by adding custom domains to the Vercel project and configuring DNS.

## Tasks

### Task 1: Add custom domains to Vercel project
- **action:** Use `vercel domains add` to register `kalebnim.dev` and `www.kalebnim.dev` on the `nim-kaleb` Vercel project
- **verify:** `vercel domains ls` shows both domains
- **done:** Domains registered on Vercel

### Task 2: DNS configuration (user action required)
- **action:** Add A record for `kalebnim.dev` → `76.76.21.21` and CNAME for `www.kalebnim.dev` → `cname.vercel-dns.com` in Google Domains DNS
- **verify:** DNS propagation confirms records resolve correctly
- **done:** Domain resolves to Vercel deployment
