# Quick Task 260519-re1: Scrape Devpost → hackathons staging data

## Goal

Pull Kaleb's real hackathon submissions from https://devpost.com/kaleb-nim and stage them
(JSON + thumbnails) for a follow-up task that swaps the fictional `HACK_ITEMS` placeholders
in `app/lib/sections.ts` for real entries. No source-of-truth code changes in this task —
the Anthropic design ref the user pointed to is auth-gated and must be pasted in before
the UI integration phase can decide which extra fields to surface.

## Scope

- **In:** scraper script, structured JSON output, downloaded thumbnails.
- **Out:** changes to `app/lib/sections.ts`, new `HackItem` fields, hackathon detail pages.

## Tasks

1. **scripts/scrape-devpost.ts** — Bun script that:
   - GETs profile page via `curl` subprocess (devpost's AWS WAF rejects plain `fetch()` UAs)
   - Parses the 13 `link-to-software` anchors
   - For each project page, extracts: title, tagline, og:image, submitted-to event + URL,
     winner labels + prize titles, team members, built-with tags, gallery photos, and
     description body (h2/p sections) flattened to markdown
   - Downloads thumbnails to `public/hackathons/<slug>.<ext>`
   - Writes consolidated `{ source, scraped_at, count, projects[] }` to
     `.planning/research/hackathons/hackathons.json`

2. **Run scraper** → 13 projects extracted, 13 thumbnails saved.

3. **Verify** — spot-check JSON (titles, prizes, thumbnail paths align with profile).

## Outputs

- `scripts/scrape-devpost.ts` (new, 235 lines)
- `.planning/research/hackathons/hackathons.json` (13 projects, ~30KB)
- `public/hackathons/*.{png,jpg,jpeg,gif}` (13 files)
